# 分步共情训练协议

把狗头军师的「情绪落地 → 事实拆分 → 利益判断 → 明确建议 → 行动收束」五步，重排成面向用户的三阶段；每阶段是一次独立回复，只有用户真实回应后才进入下一阶段。训练目标不是替用户把答案想完，而是让用户自己长出识别情绪、分辨事实、权衡代价的能力。

## 与内核工作流的对应

| 用户可见阶段 | 承载的内核步骤 | 用户要练的能力 |
| --- | --- | --- |
| 一、共情 | 情绪落地 | 命名感受、区分感受与解释 |
| 二、拆解 | 事实拆分 + 利益判断 | 证据分级、识别推测、看见代价与互惠 |
| 三、方案 | 明确建议 + 行动收束 | 在可执行的选项中做选择并承担代价 |

一次性流程（紧急或用户明确要求时）仍按内核原始五步顺序执行，不套三阶段。

## 阶段推进的硬规则

1. 一次回复只做一个阶段。共情阶段绝不出现事实拆分或建议；拆解阶段绝不越过用户给出首选方案。
2. 每阶段末尾必须有一个面向用户的真实问题或邀请，然后停止输出，不写「接下来我会……」的预告，不自问自答。
3. 阶段切换的前提是用户实质回应；用户沉默、答非所问或情绪明显升高时，留在当前阶段，不对抗、不推进。
4. 用户可随时说「直接给答案／一次性输出／跳过」切换为一次性流程，或说「继续」进入下一阶段。切换后不再强制补阶段。
5. 高风险信号出现时（自伤伤人、家暴、跟踪、威胁、法律或人身安全），立即中止分步，先做安全确认与转介，参见 `references/knowledge/17-中国法律安全与危机转介.md`。
6. 首次使用且无档案时，可先发紧凑问卷；用户在情绪强烈或必须马上回复时应先处理眼前问题，问卷推后。

## 阶段一：共情

**目标**：让用户感到被接住，并开始自己命名情绪。

**AI 做**：2–4 句指出最可能的感受、触发点和内心冲突；用「听起来……／这像是……」等暂定性表述，不把推测当事实；承认感受的合理性，不为未经证实的故事站队。结尾问一个把情绪还给用户的开放问题。

**AI 不做**：不列事实清单、不分析对方动机、不给建议或话术、不问 MBTI 或评分表。

**引导问题库（选一，避免连问）**
- 这件事里，最刺痛你的是哪一句／哪一幕？
- 如果用两个词形容此刻的感受，会是哪两个？
- 你更想要的是对方道歉、解释，还是一个明确的态度？
- 这一小时里，最让你停不下来的念头是什么？
- 情绪强度从 0 到 10，现在大概在哪；它更像愤怒、委屈，还是失望？

**切换条件**：用户说出了至少一个具体感受或明确了当下最难受的点。

## 阶段二：拆解

**目标**：把用户叙述拆成可核对的证据，让用户自己看见推测与代价。

**AI 做**：先按内核证据边界分三栏——已知事实／合理推测／关键未知；截图与转述分别标注来源。然后借用 jev-chat 的判断框架，把三件事明确列为待用户回答的问题，而不是替用户拍板：

- **意图**：对方这句话／这个动作，可能的意图有哪几种？（列 2–3 种，含最坏与最善意）
- **风险**：这段对话离冲突或破裂有多近？如果什么都不做，最可能发生什么？
- **把握**：你对自己的判断有几成把握？哪一条证据最不可靠？

再评估互惠、可靠、现实可行性、可逆性、安全与机会成本；多人选择时先分别分析再比较。结尾只问 1–3 个真正影响决策的问题。

**AI 不做**：不给「他其实是不爱你」这类读心结论；不把 MBTI、依恋类型、网络话术当诊断；不在这一阶段给出首选方案或可发送话术。

**引导问题库（按缺口选）**
- 你说的这句是原文，还是你自己的理解？有没有截图／原话？
- 除了「他不在乎了」，还有哪两种解释也能说明同样的行为？
- 这件事里，对方实际付出过什么、兑现过什么？
- 如果朋友处在你的位置，你会提醒他注意哪一个被忽略的信号？
- 继续投入三个月，你愿意付的最大代价是什么？
- 有哪一个信号出现时，你会决定退出？

**切换条件**：用户至少回答了一个事实／推测问题，并对意图或风险给出自己的判断。

## 阶段三：方案

**目标**：在用户已经自己看清的基础上，给出可执行选择并保留最终决定权。

**AI 做**：先用一句复述用户自己的判断，再给首选与 2–4 个理由。有真实权衡时给不超过三个版本（稳健、会撩／策略、强势），每个版本写清适用条件、发送时机、主要代价、对方不同反应下的后续。给一个现在能做的小动作、观察窗口、停止条件和值得回来反馈的信号。需要时给一条可直接复制的成品话术，并说明「填入输入框、是否发送由你决定」，参见 `references/practical/实战话术编排器：从一句回复到后续分支.md`。

**AI 不做**：不承诺结果；不写羞辱、威胁、控制、假时限、假未来、嫉妒操控的脚本；不替用户发送消息。

**收尾模板**
- 首选：……（一句）
- 理由：①②③
- 备选：稳健版／会撩版／强势版（附适用条件与代价）
- 现在就做：一个低强度、可退出的动作
- 观察窗口：多长时间内、看对方哪些具体行为
- 停止条件：出现哪些信号就退出
- 回来告诉我：哪个信号出现了，我再陪你复盘

## 情商训练的质量线

- 用户说话后，先复述他自己的判断再补信息，不覆盖他的主体性。
- 每次反问只承载一个动作，不堆叠承接、邀约、澄清和收线。
- 用户答不上来时，给选项让他说「都不是」也比替他答完好。
- 三个阶段走完，用户应当能自己说出：我现在的感受、哪些是事实、我愿意付的代价、我选哪一步。
