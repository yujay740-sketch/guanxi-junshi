# 关系军师 · guanxi-junshi

先共情、再拆解、最后给方案 —— 一步步陪你把关系看清，把情商练在自己身上。

以 [狗头军师](https://github.com/shengjidaguai-china/goutoujunshi)（MIT）为内核，完整保留其情绪识别、关系分析与策略推理能力及全部知识库；融入 [jev-chat](https://github.com/jev-chat/jev-chat-jarvis)（MIT）「先判断、后落笔、发送由你决定」的分步理念。默认**不一次性输出全部答案**：每阶段暂停等用户回应，用反问引导用户自己觉察情绪、分辨事实、权衡代价。

## 安装

把下面这句话发给 WorkBuddy（桌面端与手机端均可）：

```
请将公开仓库 https://github.com/<你的用户名>/guanxi-junshi 下载并安装为本地 Skill。
```

安装后系统会做安全检查并完成配置，无需额外操作。手机端也可在输入框左侧 **+ → 添加技能** 中查看和选中。

## 使用

安装后直接说：

```
使用关系军师陪我一步步梳理情绪、拆解关系，最后再给出下一步建议。
```

- **默认三阶段**：共情 → 拆解 → 方案，每阶段结束会停下来等你回应，不替你假设答案。
- **跳过分步**：说「直接给答案／一次性输出」，按内核原五步一次性给出完整分析。
- **手动添加**：若 AI 没自动启用，手机端点 **+ → 添加技能**，选中本技能即可。

### 三阶段做什么

| 阶段 | 内容 | 练什么 |
| --- | --- | --- |
| 一、共情 | 接住并命名情绪，一个开放反问交还给你 | 识别感受、区分感受与解释 |
| 二、拆解 | 分事实／推测／未知，意图·风险·把握三问 | 证据分级、看见代价与互惠 |
| 三、方案 | 首选与理由、可选版本、话术、观察窗口、停止条件 | 做选择并承担代价 |

详细协议见 `references/practical/分步共情训练协议.md`。

## 能力来源与边界

- 内核：狗头军师的 5 步工作流、20 份知识库、23 份实用指南、证据分级、事实／推测／未知分离、同意门禁的长期记忆脚本，以及全套安全边界。
- 分步：jev-chat 的判断优先与用户决定权。
- 边界：不读心、不诊断心理疾病、不承诺结果、不替用户发送消息；出现自伤伤人、家暴、跟踪等风险信号时中止分步，先做安全确认与转介。
